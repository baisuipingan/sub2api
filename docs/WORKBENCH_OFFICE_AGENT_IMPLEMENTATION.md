## 已实现结构

| 范围 | 当前实现 |
| --- | --- |
| 用户界面 | 个人工作台增加“对话助手 / 我的文件”，保留原“图片生成”。按固定 Bisheng 活跃源组件移植 Vue 页面、历史、输入、任务过程、澄清卡、成果和右侧预览；保留来源与适用许可证 |
| 对话 | 持久会话、重命名/删除、流式事件补读、停止、重新生成及候选答案选择；只有选中答案进入下一轮上下文 |
| 模型与费用 | 复用原工作台模型分组和每用户系统 Key，经原网关调用与积分账本结算；按公开模型 ID/显式档案展示官方能力，不反查私有上游模型推断语义 |
| 轻量聊天 | 独立 chat worker 池，不加载办公技能、不创建办公容器；简单问答不额外调模型生成计划或标题 |
| 受控搜索 | 工作台独立选择 DeepSeek、Brave 或 Tavily，复用搜索适配接口。查询结果进入引用卡，网页读取校验协议、目标地址、重定向、类型、大小和超时 |
| 办公运行 | DeepAgents/LangGraph + 已固定来源的 Bisheng DOCX/XLSX/PPTX 技能；模型脚本只进入固定 Linux/gVisor 执行器；支持实际重读、重算、渲染和有能力模型的页图检查 |
| 恢复 | Go 持久检查点、短期租约、epoch fencing、workspace 快照及操作 inbox；澄清暂停后恢复同一个 run；未知在途操作不自动重发 |
| 私有文件 | 原件、不可变版本、成果、必要快照与预览进入私有 S3/R2；元数据/权限在 PostgreSQL；继续修改明确绑定旧版本并保留旧成果 |
| 旧云端图库 | 通过通用资源引用展示，不搬桶、不复制图片任务；保留引用阻止原图库清理误删正在被对话使用的图片 |
| 管理端 | 对话/办公概览、任务与子调用、实际模型上游/耗时/用量/费用、用户资源与审计；复用姓名/邮箱/昵称用户搜索 |
| 限制与停用 | 工作台模型请求沿用网关的 RPM、并发与计费，任务队列、工具调用、单次输出和时长受部署保护。分别控制新对话、办公、文件、搜索的准入 |

## 服务与信任边界

- **Go 主站**管理账号、公开会话/任务状态、文件权限与原积分账本，不持有 Docker socket。
- **Python chat/office worker**使用短期 run 凭证，经 Go 模型桥调用原路由；没有用户长期 API Key，也没有数据库直连凭据。
- **可信 executor supervisor**只启动固定摘要的办公任务镜像，拥有受控 Docker 权限；不是面向用户的任意容器 API。
- **不可信任务容器**无网络、无平台凭据、非 root、只读根目录，并受 CPU/内存/PID/tmpfs/输出/时限限制。没有 Linux/runsc 或固定镜像时直接拒绝执行。
- **浏览器**只获取权限校验后的临时下载链接。PDF 按需有界读取并验证后以本地 blob 预览；按不可变版本缓存，退出账号撤销。

办公文件不放进图片任务表，不引入另一套账号或积分。工作台不会运行完整 Bisheng 服务，也不包含工作流画布、RAG、应用搭建、用户终端、任意 MCP、电脑控制或环境安装。

## 数据与接口

基线 P0 的 `dsapi_006_office_agent_control_plane.sql` 已提供独立控制面；本轮增加：

- `dsapi_007_workbench_chat.sql`：公开会话、模式、候选答案、澄清与上下文所需字段。
- `dsapi_008_office_resources.sql`：通用资源/版本、工作区快照及引用保护。

迁移为增量业务结构，不改写旧 usage 或积分账本。默认不因迁移就向用户开放办公；功能回退时停止新准入和新 worker，保留新增数据及对象，不删表/删桶。

用户 API 在 `/api/v1/workbench/chat`，管理员在 `/api/v1/admin/workbench`；worker 专用内部接口位于 `/internal/office-agent/v1`。浏览器 JWT 不能充当 worker 凭证，bootstrap token 不能直接授权某次模型操作。

## 实际验证与边界

自动测试、真实 PostgreSQL、Go/Python 跨进程、真实 Linux/gVisor 探针、真实模型计费和浏览器验收分别记录，不能互相替代。精确通过数量、真实调用 ID、已发现问题和仍未验证的供应商以 [本轮验收记录](WORKBENCH_OFFICE_AGENT_ACCEPTANCE.md) 为准。

当前测试站使用独立 PostgreSQL、Redis、私有对象存储和合成测试数据；未连接生产数据库或图库。搜索需要有效的既有供应商配置，不能把未实际执行的检索写成成功。容量规划须以实际并发办公样本继续测量，小样本并发读取不代表生产容量压测。
