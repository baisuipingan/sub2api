# 云端参考图提交

云端任务先把参考图存入私有图库，再提交生图任务；上传校验失败时尚未调用模型。
图库保留单张 32 MiB、2000 万像素的后端保护限制。

工作台在提交前检查参考图。正常图片保持原始数据；超限图片等比生成最长边 4096px
的独立提交副本，使用新的内容 ID，并提示实际尺寸。原文件、浏览器草稿和已有历史记录
不被覆盖。只有云端任务使用此预处理，浏览器直接请求及渐进预览链路保持原行为。

遮罩与目标图按相同尺寸缩放，遮罩保持 PNG；若蒙版输入转成 PNG 后超过字节上限，
整套源图、遮罩再等比缩至最长边 2560px 并重新检查。任务保存的输入、遮罩目标及后处理源
必须指向同一组提交副本，不能单独缩放蒙版或只替换请求图。

提交过程区分准备参考图、上传参考图和提交云端任务。参考图上传最多等 120 秒，
控制接口和每次状态查询最多等 20 秒；停止操作能取消在途上传。状态查询超时后继续查询
原任务，不重新发送付费请求。

后端以安全错误码区分空文件、格式、大小、像素、MIME 及解码失败。日志只记录类别、
允许的 MIME、字节和尺寸，不记录图片内容。有效 JPEG 的 `image/jpg` 和 `image/pjpeg`
别名会规范为 `image/jpeg`，实际格式校验仍保留。

“结果待确认”表示已经进入调用阶段，但没有保存到可确认的完整生成结果。
HTTP 5xx/408、调用中断、空响应或临时文件写入失败可能产生此状态。该状态不证明已经扣费，
也不表示仍在生成；系统不会自动重复调用。错误详情保留实际 HTTP 和脱敏原因。

验证覆盖实际大尺寸 JPEG 的浏览器缩放和原文件不变、源图与遮罩配对、普通参考图不重编码、
上传停止与超时、轮询恢复、审计中间件后的二进制完整性，以及 PostgreSQL 未确认状态的
错误保存、脱敏和不重复调用。测试不调用付费模型。
