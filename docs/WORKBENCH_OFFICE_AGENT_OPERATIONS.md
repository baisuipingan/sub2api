# 对话与办公工作台运维交接

本轮运行在独立测试站 `https://llm.editor.vip`，代码分支为
`codex/workbench-office-agent`。生产发布和合入主分支属于后续操作，不能把测试站验收等同于生产变更。

## 入口与配置

个人工作台包括“对话助手”（`/workbench/chat`）、“图片生成”（`/workbench/image`）和“我的文件”（`/workbench/files`）。管理员工作台包括运行概览（`/admin/workbench`）、对话记录（`/admin/workbench/chat`）、用户文件（`/admin/workbench/files`）和工作台配置（`/admin/workbench/settings`）和算力节点（`/admin/workbench/office-nodes`），以及图片管理。

在管理员工作台设置中选择统一的工作台模型分组，向该分组加入公开文本模型和图片模型。沿用每个用户原来的系统工作台 Key，不需要新增聊天 Key。对话只列出分组实际模型；自定义公开别名可明确绑定官方能力档案，不能通过私有上游映射推断语义。

普通对话、办公任务、“我的文件”和联网分别配置。“我的文件”同时控制文件入口与上传；启用办公会同时启用对话与文件，关闭对话会同时关闭办公与联网，关闭文件会同时关闭办公。部署级 `OFFICE_AGENT_ENABLED` 控制模块加载，办公节点使用各自的令牌；后台开关负责业务准入。只关闭办公不影响纯文本对话；关闭对话会隐藏对话入口并显示未启用，历史数据仍保留，重新开启后可读。“我的文件”单独开启时仍可使用。完全关闭部署级模块则其 API 不再提供服务。

在“工作台配置 → 工作台搜索供应商”（`/admin/workbench/settings#workbench-search`）选择 DeepSeek、Brave 或 Tavily，保存供应商的 API Key 后点击“测试搜索”。对话和办公共用这个选择，工作台的“联网搜索”开关控制用户是否可以使用。系统设置中的 Web Search 模拟服务于原 API 网关，拥有自己的供应商配置。工作台搜索请求使用运营者在此填写的供应商账号，模型请求仍经工作台分组结算。

## 存储和容量

在“工作台配置 → 办公文件存储”（`/admin/workbench/settings#office-storage`）选择复用备份 S3/R2、复用图片存储连接，或单独配置 S3/R2。生产使用独立的私有办公桶，复用的凭证需要该桶的对象读写权限。关闭桶的公开访问入口，设置桶 CORS 允许站点来源发送 GET 请求。办公资源使用 `workspace/v1/` 和短期签名访问。独立办公桶使用自己的生命周期，图片桶的公开域名和过期规则由图片配置管理。已有办公文件时，端点、区域、桶及寻址方式须保持一致。首次配置前可用“测试连接”检查读写、删除和签名读取，再用合成文档在实际节点和浏览器验证预览、编辑与下载。测试环境的数据库、对象和节点数据留在测试环境。

原件、不可变版本和预览进入私有对象存储；会话、权限、任务和文件元数据进入原 PostgreSQL。文件列表只读元数据，打开预览或下载才申请临时链接。原有图库通过引用呈现在“我的文件”，不复制整桶；引用保护防止旧图片清理误删仍被对话使用的对象。

当前固定文件边界为单文件和任务工作区各 24 MiB、工作区最多 64 个文件、每用户办公资源 1 GiB/1,000 个版本；原件、版本和预览计容量。不是每位用户一台常驻机器，也不是每次临时读写都请求对象存储。文档修改保存新版本，原会话成果卡仍可读取旧版。

## 运行组件

| 组件 | 职责 |
| --- | --- |
| Vue 工作台 | 推进对话的下一步，展示文件、预览和工具进度 |
| Sub2API | 会话和计费、办公节点分配、短期签名、成品交付 |
| Office Tools 容器 | Word、Excel、PPT、ZIP 和打印预览，短期过程文件和回执保存在节点本机 |
| 私有 S3/R2 | 按版本存放正式文件和预览 |

在「工作台管理 → 算力节点」登记第一台和后续节点。支持私网 HTTP 或可信公网 HTTPS。在管理端调整并发上限后，Sub2API 会将设置同步到节点。调低上限时，已开始的任务继续完成。容器镜像、CPU 和内存由节点的 Compose 设置。见[办公节点部署说明](../deploy/workbench-office-node/README.md)。

工作台每次模型请求通过原网关执行，用原有分组授权、并发、RPM 和积分账本结算。文档工具根据节点空位分配，普通对话和搜索使用各自原有链路。

## 状态、恢复和停用

Sub2API 将办公任务和按版本生成的打印预览绑定到执行节点。明确拒绝接单时可以重新选择节点。提交超时后用原任务编号查回执。成品已经上传时按大小和摘要校验，再补登记。关闭网页后，后台继续收尾已派发的文档操作，用户回到对话时可以继续推进。

维护时在后台停止接单，等待该节点完成任务和成品交付后再停机。换用新盘或新 VPS 时按新节点登记。已有交付文件和 PDF 可继续从存储桶下载。查看异常时根据对话工具记录、节点健康和存储测试定位问题。
