# 桌面客户端配置与浏览器登录

2026-11-13。本次调整保留原用户、余额、网关、托管 Key 和 bootstrap 1/2/3 合同，不部署生产。

## 配置页面

- 父页面是唯一草稿所有者，保留 active、请求代次、step-up 与不可变保存快照。
- 常用配置仅计费组、公开模型、默认模型、默认推理档位及 Agent 单次输出上限。模型能力摘要只读；完整能力编辑与协议兼容项放高级区域。
- `default_max_output_tokens` 保留线协议名，界面准确称为单次输出上限，不能称推荐默认值。物理最大输出与上下文只在高级覆盖中修改。
- 能力档案来自 `GET /admin/desktop/profiles` 的内置官方资料，展示来源、核对日期和当前执行器限制；旧保存声明不再作为模板。已知公开 ID 自动套用，未知别名显式关联，目标公开 ID、展示名和默认模型归属保留，不按前缀猜测或回溯私有模型名。高级声明须明确启用覆盖，默认只读。
- 档案读取失败保留草稿并允许独立重试，阻止未验证配置发布；不能回退为旧声明模板。组模型目录仍为保存所需校验。官方上下文与当前客户端上下文预算分开显示，none 表示省略 effort，不能称为关闭推理。
- 模型清单准确称客户端目录，真正调用权限仍由 Key 和分组策略决定。

## 浏览器授权

- `/desktop/authorize` 是需登录但不需管理员的独立页面，复用原登录守卫保存完整 `to.fullPath`；网站登录、验证码、二步验证完成后回到该页面。
- 仅支持 `client_id=zcode-desktop`、`response_type=code`、`code_challenge_method=S256`、43字符 base64url challenge、非空有界 state、精确 `http://127.0.0.1:<port>/callback` 回调；拒绝重复参数、认证信息、query、fragment和其他主机。
- 不自动授权；页面显示本人账户、客户端及本地回调，并解释模型消费使用本人余额。
- 明确确认后提交冻结的参数到 `POST /desktop/auth/authorize`；只接受原回调的 origin/path、精确 state、单个非空 code及无其他字段的返回 URL，再导航回本机。
- 取消不生成授权码、不请求 authorize API；只返回已严格校验的本机回调，携带 `error=access_denied` 和原 state，让桌面立即结束等待。无有效请求不得导航；卸载/换路由后的迟到响应不导航。
- 错误显示安全固定文案，不把后端错误详情和凭据展示给浏览器。

## 凭据操作

- 用户 Key 列表仅对使用中的 `purpose=desktop_agent` 系统 Key 提供专用撤销/轮换动作，不借普通编辑/删除绕过托管保护。服务端撤销态原样返回 `disabled`，不与普通 Key 的 `inactive` 混用；用户不能恢复任何非使用中的 Key，撤销后提示联系管理员。
- 撤销与轮换均需确认，说明同用户所有设备及已复制 Key都会受影响。撤销不自动重建；只有管理员能恢复已撤销的 Key。
- 前端不接收操作返回的 Key 明文；成功后重载服务器事实，不在本地猜造新 Key 状态。
- 管理入口复用“用户管理 → 更多 → API密钥”弹窗，仅对准确 purpose 的托管 Key 显示撤销/恢复；只恢复 `disabled` 且未过期、未耗尽的 Key。沿用既有管理员 step-up 规则，确认冻结 user_id/key_id，验证期间切换用户或关闭弹窗不得重试旧操作。托管 Key 的分组只读，普通 Key 不变。

## 回归场景

- 现有模型字段完整往返、草稿不被迟到配置覆盖、组目录失败不误保存、step-up取消不重试；常用项与高级覆盖分开；模板套用不改变公开ID或默认选择，模板失败可继续编辑。
- 匿名授权重定向保留全部 query；验证码登录仍回到授权；明确点击前不发 authorize；伪造回调/state/重复参数被拒；提交期间换路由或卸载不导航；取消不提交。
- 只有本人 Agent Key出现专用动作，其他系统Key继续受保护；撤销/重置拒绝和重载失败准确报告，不把已执行成功错误描述成未执行。
