# 控制台与工作台

用户侧与管理员共用 Logo 下方的「控制台 / 工作台」入口。区域和管理上下文由路由决定，导航记忆只保存返回位置，不改变权限。

| 区域 | 管理员上半区 | 管理员下半区 | 普通用户 |
| --- | --- | --- | --- |
| 控制台 | 现有平台管理 | 我的账户 | 现有个人功能 |
| 工作台 | 运行概览、生成任务、工作台配置 | 我的创作 → 图片生成 | 图片生成 |

## 路由与状态

- `/workbench/image`：原生图工作台，名称为「图片生成」，保留现有生成交互。
- `/image-studio` 和 `/workbench`：兼容重定向，保留 query 与 hash。
- `/admin/workbench`、`/admin/workbench/tasks`、`/admin/workbench/settings`：管理员工作台。
- 区域切换保留管理员管理/个人使用上下文；返回页面与侧栏滚动按账号、区域、上下文区分，同标签页内记忆，退出或换账号清理。
- 桌面保持 220px/58px 侧栏契约；折叠态使用公共 Select，手机抽屉内显示完整分段入口。
- 导航不清空图片 store，不中止或重新提交模型请求。服务端任务和浏览器渐进请求仍复用已有生命周期；浏览器请求在关页后继续执行不属于本轮承诺。

## 工作台管理接口

管理接口沿用现有管理员鉴权、审计、合规校验与限流，受限管理密钥没有自动获得新权限。

- `GET /api/v1/admin/workbench/overview?days=7|30|90`：时段内云端执行任务聚合，当前队列与图库资产另行统计。
- `GET /api/v1/admin/workbench/tasks?page=1&page_size=20&status=&user_id=&model=`：有界分页，只读安全元数据。用户和模型为精确筛选。
- `GET/PUT /api/v1/admin/workbench/config`：只读写 `image_studio_enabled`、`image_studio_group_id` 两个现有键；保存需要原有二次验证。

任务列表不返回提示词、图片 URL、参考图、上游原始错误、密钥或临时文件路径。首期无一键重新生成等收费动作。

全站列表以用户 ID 与任务 ID 组成复合行标识，兼容不同用户提交相同任务 ID。

## 数据口径

- 生成任务只计未删除的服务端执行任务，不含旧本机任务、渐进模式、外部 API 和历史导入。用户删除或取消产生的墓碑被排除。
- 完整成功率为 `completed / (completed + partial + failed)`；无分母显示「—」，部分成功、取消和结果不确定分别展示。
- 计划子调用包含尚未发出的排队记录，不是实际上游请求数或计费次数。
- 队列是跨时间的当前快照，结果待确认不会自动重发。
- 图库资产包含已有导入历史，空间与当前图库配额口径一致，包含原图、预览和缩略图；不是整个对象存储桶的实时用量。

## 配置唯一来源

图片入口与使用分组在工作台配置页独立保存。原系统设置移除这两个字段的全量提交，避免旧表单覆盖新配置。

后端系统设置接口也将未提供或为 null 的这两个字段从实际写入中剔除，避免并发保存时写回旧快照；旧客户端明确提交的字段仍保持兼容。

图库、原生异步生图和服务端执行继续使用已有图片存储设置及各自独立开关。备份页改为配置跳转，备份 S3 本身不迁移、不复制。对象存储校验、私有桶提示、密钥保留语义、存储目标保护和二次验证全部沿用。

本轮不新增数据库表，也不修改网关鉴权、模型能力、尺寸映射、计费或任务执行器。

发版沿用 schema epoch 2，支持通过切换镜像回退到同为 epoch 2 的 `0.2.20-ds.3`，无需还原数据库；部署前仍自动备份。epoch 1 的旧镜像不具备持久任务能力，继续禁止直接回退。回退到旧界面后，新工作台地址须改用旧 `/image-studio` 入口。

## 验收记录

路由/侧栏测试覆盖四种管理员区域组合、普通用户、模式限制、旧链接、账号隔离、Ctrl/Meta 点击、折叠选择和手机入口；管理 API 测试覆盖真实权限、受限密钥拒绝、参数边界、私有字段不返回和配置字段隔离。

真实 PostgreSQL 定向测试覆盖时段与快照区别、资产/任务统计、删除用户与墓碑排除、计划子调用、精确筛选和稳定分页。

Playwright 使用模拟接口运行实际应用：桌面与 375px 设置/任务页面无横向溢出；58px 区域选择完整可用；普通用户隐藏管理入口，直达管理页被路由拦截；云任务与 SSE 任务生成期间来回导航后请求次数均保持 1，草稿和结果保留。此验收未发出真实收费模型请求。

## 图片参数契约

图片生成按模型列表最终公开的模型 ID 匹配官方参数族。供应商的私有名称、模型映射和同一公开模型背后的其他型号不参与参数交集，不再导致已知公开型号退回未知参数。未知公开型号保持最小参数，不借用其私有目标的官方身份。

模型列表仍须通过现有路由和账号准入检查，协议由已有接口路径确定；`available_size_tiers` 继续反映实际允许的尺寸并禁用不可用档位。订阅桥接仅保留其已有传输限制。此变更不改写实际请求模型名、调度顺序、尺寸路由和计费。云任务提交和执行使用同一个公开参数契约。

管理员生成任务新增实际上游列，使用稳定子调用请求 ID、用户 ID 和内部 API Key ID 精确关联用量与运维错误日志，展示供应商账号与实际模型及已留痕的失败重试。未返回的请求显示记录待返回，未派发、历史无留痕与实际模型未留痕分别标注；不会拿当前路由配置或公开/计费名称推断历史目标。只有管理员 DTO 返回这些信息，用户任务接口不增加上游数据。

本次参数契约切换在发布前确认执行队列为空，不改写旧任务的请求快照。旧页面携带不一致的参数族时，提交在创建任务前返回 409 `MODEL_ROUTE_CHANGED` 并要求刷新模型列表；旧任务 ID 的幂等读取保持原样，已完成记录不受影响。回退前同样应排空执行队列。

## 图像错误与结束时间

兼容 Images API 的 HTTP 成功状态不能替代业务成功。API Key 非流式响应如明确返回错误、无效 JSON 或没有图片载荷字段，返回明确业务错误且不生成按图用量；审核拒绝不触发其他供应商重试。已存在图片的混合响应保留实际输出和既有计费，不把后续图库处理失败当作上游未出图。

云任务识别 keepalive 后的错误 JSON，保存稳定错误码及脱敏原因，用户和管理员都能看到可读原因并展开技术详情。用户任务不增加供应商账号、端点或凭据字段。管理员上游摘要标注最终有用量记录的账号，展开列表才表示请求内的尝试顺序。

每次执行结束后立即尝试确认已有计费记录并汇总父任务；二十秒扫描仅做恢复与补偿，扫描中先确认计费再选择可结束的任务。明确审核拒绝取消同任务尚未派发的生成请求。已产图、计费待确认和仍在执行的请求不被提前结束，也不会重新调用模型。父任务完成时间取最后一个请求的实际结束时间，更新时间记录归档时刻，避免将补偿等待算入执行耗时；用户耗时以服务端入队时间为起点。

## 管理员云端图库

新增 `/admin/workbench/gallery`，从工作台侧栏、概览图库卡片和生成任务的「查看图片」进入。独立图库覆盖已归档云端结果及导入历史，按用户 ID 和任务 ID 精确筛选、分页；生成任务入口自动带上这两个筛选条件。

管理 API 列表只投影用户、公开模型、任务、时间和结果图片 ID，不返回原始任务 JSON、提示词、参考图、蒙版、存储 key 或 URL。单图授权必须匹配未删除用户、未删除任务和 `role=output` 关联，资产须为 ready 并匹配当前私有存储目标。受限管理密钥和普通用户均无权读取，敏感 GET 访问进入审计。

网格接近视口时才请求 480px 缩略图临时链接，点击后请求现有 1600px 预览，两个变体均复用十分钟预签名；管理员接口拒绝 original。链接只保存在组件内存，筛选、卸载和预览关闭时取消相应请求，旧响应不能回写；加载失败提供有限重签与重试。图片设置 no-referrer，授权 JSON 返回 no-store。未同步的本机历史不在云端图库中。
