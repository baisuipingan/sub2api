# 平台币种与支付改造实施计划

- [ ] 统一充值报价和下单校验。合并 USDT 与易支付等法币渠道的计价。使用当前平台币种和基础汇率，报价过期或配置变化时重新确认。给重复下单、回调和查单设置幂等边界。
- [ ] 更新后台和用户页面。取消单笔币种切换，显示渠道实际能力、规则的计价单位、预计到账和实际到账。按渠道及订单的退款能力显示操作。
- [ ] 验证账务和历史订单。核对两种币种、旧单付款、待支付和已付款状态、入账流水、限额、优惠和退款保护。易支付用协议测试验证，商户联调安排在实际启用前。
- [ ] 验证发布和恢复。先跑本地代码检查、数据库集成和界面测试，再构建固定来源的镜像。上线前核对生产订单、配置和备份。上线后核对 USD 充值、取消测试单、复核旧订单及余额流水。

生产配置目前为 USD、1 USD = 6.75 CNY，只有 USDT（BEP20）开放。微信、支付宝和易支付的启用状态由本次任务的既有配置决定。后台现有人民币等值限额按原值兼容迁移，避免把最低 ¥1 当作 $1。
